# 拾景纸刊 Skill 使用说明

来源：[Zeejay0/gathered-scenes-zine-skill @ e764b7f](https://github.com/Zeejay0/gathered-scenes-zine-skill/tree/e764b7fd243d7cc501723b9d325279bf6dd852c2/skills)（MIT 许可，见 `LICENSE`）

## 里面有什么

| Skill | 作用 | 成品里有没有原照片 |
| --- | --- | --- |
| `scenes-gathered-zine-v1-3`（实景拼贴） | 照片保留为真实锚点，周围长出抽象插画、一个高饱和色块和手撕纸边，3:5 竖版 | 有 |
| `scene-distillation-zine-v1-3`（影像蒸馏） | 照片只当灵感，重新画成极简纸刊插画，文字自由；竖图出 3:5、横图出 5:3；支持「单色块模式」 | 没有 |

每个 Skill 就是一个 `SKILL.md`（一大段给 AI 看的创作规则）加一个 `agents/openai.yaml`（Codex 里的显示名和默认提示词）。**Skill 本身不会生图**，它只是告诉 AI 怎样分析照片、怎样写生图提示词，真正出图要靠一个图片模型。

## 用法一：在电脑上用 Codex（原作者设计的方式）

1. 把两个文件夹复制到 `~/.codex/skills/`（或项目里的 `.codex/skills/`）。
2. 在 Codex 里上传照片，然后说：

```text
用 $scenes-gathered-zine-v1-3 把这张照片做成一张拾景纸刊海报。保留人物与海岸线的关系，文字用中文。
```

```text
用 $scene-distillation-zine-v1-3 重新创作这张照片。不要保留照片本身，让作品表达"靠近与错过"。
```

```text
用 $scene-distillation-zine-v1-3 的单色块模式处理这张图片
```

Codex 自带生图工具，会直接返回图片和一段中文创作说明。

## 用法二：手机上最省事，不用 API

**ChatGPT App（自带生图）**

1. 新建一个 Project（或自定义 GPT），把其中一个 `SKILL.md` 的全文粘到「Instructions / 指令」里。
2. 在这个 Project 里发照片，再写一句「按指令把这张照片做成海报」。

ChatGPT 会按 Skill 的规则写提示词并直接出图，额度算在你的 Plus/Pro 订阅里，不需要 API Key。

**Claude App**：在 设置 → Capabilities/Skills 里上传 `*.zip` 就能用，但 Claude 自己不能出图，只能帮你写好生图提示词，再拿去下面的 API 流程里生图。

## 用法三：手机直接调用 OpenAI 图片 API

### 1. 准备 API Key

- 电脑或手机浏览器打开 <https://platform.openai.com> → Billing 充值 → API keys → Create new secret key。
- 图片模型（`gpt-image-1` 系列）通常要求账号先在 Settings → Organization 里完成 **Verify Organization**（身份验证）才能调用。
- Key 只保存在自己手机里，不要发给别人，也不要填到来路不明的网站或代充站。

### 2. 选一个手机客户端

**A. 支持自定义 OpenAI Key 的 App（最简单）**

例如 Chatbox、OpenCat（iOS）、Pal 等：填入 API Key，模型选图片模型（如 `gpt-image-1`），把 `SKILL.md` 内容设为系统提示词 / 角色。具体能否「上传照片做参考图」要看该 App 是否支持图片编辑接口，不支持的话只能纯文字生图。

**B. iPhone「快捷指令」直接调接口（能传参考照片）**

这正是 Skill 需要的「照片 + 提示词 → 新图」，用的是 `/v1/images/edits` 接口：

1. 动作「选择照片」。
2. 动作「文本」：写提示词（可以先让 ChatGPT/Claude 按 `SKILL.md` 帮你生成）。
3. 动作「获取 URL 内容」：
   - URL：`https://api.openai.com/v1/images/edits`
   - 方法：`POST`
   - 头部：`Authorization` = `Bearer sk-你的key`
   - 请求体：**表单（Form）**
     - `model` = `gpt-image-1`
     - `image` = 文件 → 第 1 步的照片
     - `prompt` = 第 2 步的文本
     - `size` = `1024x1536`（竖版；横版用 `1536x1024`）
     - `quality` = `high`（可选，越高越贵）
4. 动作「获取词典值」：键 `data` → 「获取列表中的项目」第 1 项 → 再取键 `b64_json`。
5. 动作「Base64 解码」→「存储到相册」。

> 说明：`gpt-image-1` 只支持 1024×1024、1536×1024、1024×1536，没有严格的 3:5 / 5:3；想要精确比例，出图后在相册里裁一下就行。

**Android**：用 HTTP Shortcuts、Tasker 等 App，按上面同样的参数发 `multipart/form-data` 请求即可。

### 3. 先在电脑上测通（可选）

```bash
curl https://api.openai.com/v1/images/edits \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -F model=gpt-image-1 \
  -F image=@photo.jpg \
  -F size=1024x1536 \
  -F quality=high \
  -F prompt="（按 SKILL.md 写好的提示词）" \
  | python3 -c "import sys,json,base64;open('out.png','wb').write(base64.b64decode(json.load(sys.stdin)['data'][0]['b64_json']))"
```

### 4. 推荐的手机工作流

1. 在 ChatGPT / Claude App 里（已装好 Skill 指令）发照片，说「只输出英文生图提示词，不要生图」。
2. 复制提示词 → 运行快捷指令 → 选同一张照片 → 粘贴提示词 → 图片存到相册。

## 注意

- 两个 Skill 都会把照片和提示词发送给生图服务，介意隐私的照片别用。
- API 按张收费，`quality=high` 的竖版图比 `medium` 贵好几倍，测试时先用 `low`/`medium`。
- OpenAI 的模型名、尺寸和价格会更新，以 <https://platform.openai.com/docs/guides/image-generation> 为准。
